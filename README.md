# One Emoji, One Dream Vacation 🗻

Entry for the make.fun competition [One Emoji, One Dream Vacation](https://make.fun/competitions/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35).

The program (`main.ts`, Node 22) writes exactly one emoji — Mount Fuji 🗻 — to `/output/entry.txt`, with no trailing newline. One mountain, one destination, one dream: snow-capped Fuji as a postcard for Japan.

Run it with `node main.ts`. It verifies the file afterwards, failing loudly if the entry is not exactly one emoji.
